## 📂 Repository Structure

Each module contains isolated practice examples to prevent namespace conflicts:

* `basic-types/` - Go basic primitive types
* `constants/` - Constant declarations & numeric precision
* `for/` - Flow control and iteration loops
* `functions/` - Function signatures & multiple return values
* `type-conversions/` - Type conversion and inference rules
